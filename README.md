🕒 Digital Clock Web Application

A sleek, modern, and responsive Digital Clock Web Application built using HTML, CSS, and JavaScript.

Designed with simplicity and elegance, this application displays the current time in real-time with a clean interface. It provides an easy way to keep track of time while exploring the fundamentals of modern web development.

✨ Features

- 🕒 Real-Time Clock: Displays the current time with automatic updates every second.
- 📅 Date Display: Shows the current date and day.
- 🔄 Automatic Updates: Keeps the displayed time synchronized with the system clock.
- 🎨 Modern UI: Clean, minimal, and visually appealing interface.
- 📱 Responsive Design: Compatible with desktops, tablets, and smartphones.
- ⚡ Lightweight & Fast: Smooth performance without unnecessary dependencies.

⚙️ How It Works

The application uses JavaScript's built-in "Date()" object to retrieve the current system time and date.

- "getHours()" – Retrieves the current hour.
- "getMinutes()" – Retrieves the current minutes.
- "getSeconds()" – Retrieves the current seconds.
- "setInterval()" – Refreshes the clock every second.

CSS is used to create the visual appearance, while HTML provides the overall structure.
